# 交易看板 V2 实施文档

本目录用于本轮「自选池/市场异动/点位一致性/资产分析」改造的统一规范与执行记录。

- `design-consistency.md`: 前端设计一致性规范与交互规则
- `technical-consistency.md`: 后端接口、数据流、兼容策略
- `todo.md`: 分阶段执行清单（可勾选）
- `core-memory.md`: 全局核心约束与产品记忆（不随实现细节漂移）
- `debug-log.md`: 调试记录、问题复盘、验证结果

实施原则：
1. 先保证一致性，再做扩展。
2. 所有改动必须可回滚、可测试、可验证。
3. 前后端字段命名和语义必须单一来源。
