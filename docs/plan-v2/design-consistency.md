# 前端设计一致性文档（V2）

## 1. 信息层级
- 一级：当前决策（操作建议、持仓动作、点位）
- 二级：输入参数（我的配置、现金、状态）
- 三级：来源解释（AI建议来源、报告时间、筛选条件）

## 2. 自选池一致性
- 持仓状态(`holding`)在 `全部` 与 `收藏` 视图始终置顶。
- 卡片标题优先显示股票名称，副标题显示代码。
- 卡片字段固定顺序：买入价 -> 仓位 -> 现价/涨跌。

## 3. 历史记录一致性
- 每条历史记录提供 `查看` 与 `加入自选` 两个明确动作。
- `加入自选` 不改变当前分析上下文，仅修改交易档案。

## 4. 市场异动一致性
- 分为「快速查看」与「预扫描评分」两种模式，默认快速查看。
- 预扫描模式必须显示：任务进度、已评分数量、筛选条件。
- 板块筛选条件（关键词、最小涨跌幅）必须可见且可重置。

## 5. 点位一致性
- 配置框显示两条线：
  - 我的目标（可编辑）
  - AI建议（只读）
- 只有点击“同步”才允许 AI 覆盖我的目标。
- 同步后写入数值字段，避免字符串截断误差。

## 6. 资产分析一致性
- 首页展示摘要卡：行业集中风险、仓位健康度、买入清单。
- 提供“展开深聊”入口到 chat，保留完整推理链路。

## 7. 反馈文案
- 空态必须可解释，例如：
  - “暂无符合 min_score 与板块筛选条件的标的”
  - “请先执行预扫描评分后再按分数筛选”
